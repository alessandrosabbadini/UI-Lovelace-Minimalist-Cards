# chip_icon_state

Icon + state chip

## New editable card

```yaml
type: custom:ulm-chip-icon-state-card
```

Add from the UI card picker (**ULM Chip…**) or as a **view badge** (Edit dashboard → Badges).

## Migration

Old Minimalist YAML used `template: chip_icon_state` on `custom:button-card`.
Use `custom:ulm-chip-icon-state-card` instead and configure fields from the visual editor.
