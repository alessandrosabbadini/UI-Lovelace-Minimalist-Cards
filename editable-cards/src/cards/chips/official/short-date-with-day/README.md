# chip_short_date_with_day

Short date chip

## New editable card

```yaml
type: custom:ulm-chip-short-date-with-day-card
```

Add from the UI card picker (**ULM Chip…**) or as a **view badge** (Edit dashboard → Badges).

## Migration

Old Minimalist YAML used `template: chip_short_date_with_day` on `custom:button-card`.
Use `custom:ulm-chip-short-date-with-day-card` instead and configure fields from the visual editor.
