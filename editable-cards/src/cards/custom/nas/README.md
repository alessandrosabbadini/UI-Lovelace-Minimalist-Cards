# Custom-card "NAS"

Lit port of `custom_card_nas` — simple blue icon_info for a NAS metric sensor.

```yaml
type: custom:ulm-custom-card-nas-card
entity: sensor.nas_volume_used
name: Nas
text: Used
unit: "%"
icon: mdi:nas
```

Legacy: `ulm_custom_card_nas_sensor`, `ulm_custom_card_nas_text`, `ulm_custom_card_nas_unit`.
