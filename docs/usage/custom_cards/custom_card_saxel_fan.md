# Custom-card "Saxel Fan"

Lit port of `custom_card_saxel_fan` — fan with slider, oscillate button, and optional temp/hum attributes. Use `variant_blue: true` for the filled blue-on look.

```yaml
type: custom:ulm-custom-card-saxel-fan-card
entity: fan.living_room_fan
enable_slider: true
enable_button: true
enable_collapse: true
color: blue
# optional:
# variant_blue: true
# ulm_card_fan_horizontal: true
# ulm_card_fan_temp_attribute: temp
# ulm_card_fan_hum_attribute: hum
# oscillate_attribute: oscillate
```
