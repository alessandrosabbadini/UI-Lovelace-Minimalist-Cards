# chip_icon_label

Icon + label chip

## New editable card

```yaml
type: custom:ulm-chip-icon-label-card
```

Add from the UI card picker: search for **ULM Chip**.

## Migration

Old Minimalist YAML used `template: chip_icon_label` on `custom:button-card`.
Use `custom:ulm-chip-icon-label-card` instead and configure fields from the visual editor.
