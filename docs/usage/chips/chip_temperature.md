# chip_temperature

Temperature chip

## New editable card

```yaml
type: custom:ulm-chip-temperature-card
```

Add from the UI card picker: search for **ULM Chip**.

## Migration

Old Minimalist YAML used `template: chip_temperature` on `custom:button-card`.
Use `custom:ulm-chip-temperature-card` instead and configure fields from the visual editor.
