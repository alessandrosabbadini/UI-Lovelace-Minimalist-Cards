# chip_presence_detection

Presence chip

## New editable card

```yaml
type: custom:ulm-chip-presence-detection-card
```

Add from the UI card picker: search for **ULM Chip**.

## Migration

Old Minimalist YAML used `template: chip_presence_detection` on `custom:button-card`.
Use `custom:ulm-chip-presence-detection-card` instead and configure fields from the visual editor.
