# chip_power_consumption

Power consumption chip

## New editable card

```yaml
type: custom:ulm-chip-power-consumption-card
```

Add from the UI card picker: search for **ULM Chip**.

## Migration

Old Minimalist YAML used `template: chip_power_consumption` on `custom:button-card`.
Use `custom:ulm-chip-power-consumption-card` instead and configure fields from the visual editor.
