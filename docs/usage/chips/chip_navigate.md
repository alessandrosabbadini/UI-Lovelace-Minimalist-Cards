# chip_navigate

Navigate chip

## New editable card

```yaml
type: custom:ulm-chip-navigate-card
```

Add from the UI card picker: search for **ULM Chip**.

## Migration

Old Minimalist YAML used `template: chip_navigate` on `custom:button-card`.
Use `custom:ulm-chip-navigate-card` instead and configure fields from the visual editor.
