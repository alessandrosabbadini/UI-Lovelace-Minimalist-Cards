# chip_weather_date

Weather date chip

## New editable card

```yaml
type: custom:ulm-chip-weather-date-card
```

Add from the UI card picker: search for **ULM Chip**.

## Migration

Old Minimalist YAML used `template: chip_weather_date` on `custom:button-card`.
Use `custom:ulm-chip-weather-date-card` instead and configure fields from the visual editor.
