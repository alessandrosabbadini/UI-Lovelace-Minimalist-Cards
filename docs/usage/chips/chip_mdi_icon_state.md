# chip_mdi_icon_state

MDI icon + state chip

## New editable card

```yaml
type: custom:ulm-chip-mdi-icon-state-card
```

Add from the UI card picker: search for **ULM Chip**.

## Migration

Old Minimalist YAML used `template: chip_mdi_icon_state` on `custom:button-card`.
Use `custom:ulm-chip-mdi-icon-state-card` instead and configure fields from the visual editor.
