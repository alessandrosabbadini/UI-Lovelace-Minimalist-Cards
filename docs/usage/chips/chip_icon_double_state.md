# chip_icon_double_state

Two-state chip

## New editable card

```yaml
type: custom:ulm-chip-icon-double-state-card
```

Add from the UI card picker: search for **ULM Chip**.

## Migration

Old Minimalist YAML used `template: chip_icon_double_state` on `custom:button-card`.
Use `custom:ulm-chip-icon-double-state-card` instead and configure fields from the visual editor.
