# chip_mdi_icon_only

MDI icon only chip

## New editable card

```yaml
type: custom:ulm-chip-mdi-icon-only-card
```

Add from the UI card picker (**ULM Chip…**) or as a **view badge** (Edit dashboard → Badges).

## Migration

Old Minimalist YAML used `template: chip_mdi_icon_only` on `custom:button-card`.
Use `custom:ulm-chip-mdi-icon-only-card` instead and configure fields from the visual editor.
