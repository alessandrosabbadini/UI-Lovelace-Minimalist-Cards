# chip_alarm

Alarm chip

## New editable card

```yaml
type: custom:ulm-chip-alarm-card
```

Add from the UI card picker (**ULM Chip…**) or as a **view badge** (Edit dashboard → Badges).

## Migration

Old Minimalist YAML used `template: chip_alarm` on `custom:button-card`.
Use `custom:ulm-chip-alarm-card` instead and configure fields from the visual editor.
