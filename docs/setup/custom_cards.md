Community / custom cards are **already ported** into the Lit package. They appear
in the card picker as `custom:ulm-custom-card-*-card` (search **ULM**).

You do **not** need to copy YAML from a `custom_cards/` folder or select cards in
an integration options dialog.

## Find a card

- Docs: [Usage → Custom cards](../usage/custom_cards/custom_card_bar_card.md)
- Sources + README: `editable-cards/src/cards/custom/<name>/`
